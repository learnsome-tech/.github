# LearnSome.tech

Labs, exercises and code for the [LearnSome.tech](https://learnsome.tech) courses: cloud architecture, systems and production engineering.

Every course has one repository. Each holds a `labs/<lessonId>/` folder per lesson with the artifact files shown in the lesson video, an `EXERCISES.md` with the lesson's tasks and hints, and links back to the video and to the matching section of the companion handbook.
